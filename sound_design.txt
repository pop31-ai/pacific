ДОКУМЕНТ ПО ЗВУКОВОМУ ДИЗАЙНУ (SOUND DESIGN)
=============================================
Проект: "Пирожки с нуля: Тесто Времени"
Формат: HTML5 Canvas анимация (звук — через Web Audio API)

==================================================
1. ОБЩАЯ КОНЦЕПЦИЯ
==================================================

Фильм должен звучать как уютная кухня: шипение, тиканье часов, мягкие звуки
инструментов. Звуковая дорожка создаёт атмосферу домашнего уюта и процесса
приготовления пищи.

==================================================
2. МУЗЫКАЛЬНЫЕ ТРЕКИ (BGM)
==================================================

ТРЕК 1: "Утро на кухне" (Scenes 1-2, 00:00-04:00)
─────────────────────────────────────────────────────
- Стиль: нежный пианино + акустическая гитара
- Темп: 70-80 BPM (спокойный, утренний)
- Настроение: свежесть, уют, начало процесса
- Инструменты: фортепиано, акустическая гитара, мягкие струнные
- Громкость: тихая (20-30%), создаёт фон
- Примерный звук: "Piano & Acoustic Guitar - Morning Kitchen"

ТРЕК 2: "Замешиваем тесто" (Scene 3, 04:00-07:00)
─────────────────────────────────────────────────────
- Стиль: более ритмичный, с perkusicными элементами
- Темп: 100-110 BPM (средний, процессуальный)
- Настроение: энергичность, движение, творчество
- Инструменты: перкуссия (cajon, shaker), фортепиано, струнные
- Громкость: средняя (30-40%), поддерживает энергию
- Примерный звук: "Upbeat Acoustic - Making Dough"

ТРЕК 3: "Тишина ожидания" (Scene 4, 07:00-09:00)
─────────────────────────────────────────────────────
- Стиль: минималистичный, ambient
- Темп: 50-60 BPM (медленный, ожидание)
- Настроение: терпение, время течёт, ничегонеделание
- Инструменты: мягкие синты, обертоны, эмбиент
- Громкость: очень тихая (15-20%), почти не слышен
- Примерный звук: "Ambient Waiting - Dough Rising"

ТРЕК 4: "Кулинарный джаз" (Scene 5, 09:00-11:00)
─────────────────────────────────────────────────────
- Стиль: лёгкий джаз
- Темп: 90-100 BPM (средний, энергичный)
- Настроение: действие, трансформация, aromat
- Инструменты: саксофон, фортепиано, контрабас
- Громкость: средняя (30-40%), ритмичная
- Примерный звук: "Light Jazz - Kitchen Cooking"

ТРЕК 5: "Артистическая лепка" (Scene 6, 11:00-13:00)
─────────────────────────────────────────────────────
- Стиль: лиричный, с элементами классики
- Темп: 70-80 BPM (спокойный, сосредоточенный)
- Настроение: мастерство, точность, красота
- Инструменты: скрипка, фортепиано, арфа
- Громкость: тихая (20-30%), подчёркивает элегантность
- Примерный звук: "Elegant Classical - Shaping Pastries"

ТРЕК 6: "Финальное ожидание" (Scene 7, 13:00-14:30)
─────────────────────────────────────────────────────
- Стиль: нарастание, crescendo
- Темп: постепенно ускоряется (80 → 120 BPM)
- Настроение: напряжение, ожидание, первый результат
- Инструменты: струнные + фортепиано, нарастание громкости
- Громкость: тихая → средняя (15% → 40%)
- Примерный звук: "Building Anticipation - Oven Baking"

ТРЕК 7: "Дегустация" (Scene 8, 14:30-15:00)
─────────────────────────────────────────────────────
- Стиль: лирический, эмоциональный
- Темп: 70 BPM (медленный, чувственный)
- Настроение: удовлетворение, радость, наслаждение
- Инструменты: фортепиано, струнные, мягкие духовые
- Громкость: средняя (30-35%), эмоциональный пик
- Примерный звук: "Satisfied Ending - Tasting Scene"

3. ЗВУКОВЫЕ ЭФФЕКТЫ (SFX)
==================================================

КУХОННЫЕ ЗВУКИ:
──────────────
- Water pouring         — лейка, тёплая вода → миска
- Sizzle/frying         — шипение масла, лук, фарш
- Chop/chop/chop        — нож по доске (лук)
- Clap (хлопок)         — хлопок в ладоши (вход шефа)
- Oven door open/close  — дверца духового шкафа
- Timer tick            — тиканье таймера
- Timer ding            — звон таймера (сигнал готовности)
- Rolling pin           — скалка по тесту
- Dough squish          — замешивание теста (мягкое squish-squish)
- Egg crack             — разбивание яйца
- Crack/crunch          — хруст при разрезе готового пирожка

БЫТОВЫЕ ЗВУКИ:
──────────────
- Footsteps             — шаги по кухне (мягкие)
- Book page turn        — страница книги
- Clink (стакан)        — стакан на столе
- Fabric rustle         — шуршание полотенца
- Chair squeak          — скрип стула

ЗВУКИ ПЕРСОНАЖЕЙ:
──────────────────
- Voice-over (Шеф)      — 52 реплики
- Voice-over (Диктор)   — 35 реплик
- Laugh track           — после каждой сцены
- Satisfaction sigh     — выдох удовольствия

5. МИКСАЦИЯ (MIXING)
==================================================

УРОВНИ ГРОМКОСТИ:
─────────────────
BGM (фоновая музыка):     -20 dB (тихо)
Voice-over (реплики):     -6 dB (ярко, чётко)
SFX (звуки):              -12 dB (средне)
Laugh track:              -15 dB (средне-тихо)

ПРИОРИТЕТЫ (Priority Stack):
1. Voice-over — ВСЕГДА на первом плане
2. SFX — на заднем плане, не перекрывают голос
3. BGM — самый тихий слой, создаёт атмосферу
4. Laugh track — между сценами, после сцены

АВТОМАТИЧЕСКИЙ ДАХИНГ:
──────────────────────
- Когда говорит Шеф или Диктор → BGM снижается на 6-10 dB
- Когда нет голоса → BGM на полной громкости
- Laugh track → BGM снижается на 3-6 dB

7. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
==================================================

- Формат: MP3 или OGG для веб
- Частота дискретизации: 44.1 kHz
- Битрейт: 128 kbps (MP3) / 160 kbps (Vorbis)
- Громкость по умолчанию: 80%
- Возможность отключения BGM/SFX/Voice отдельно
- Web Audio API: AudioContext для манипуляций
- Фейды: fade-in 0.5s, fade-out 1s

==================================================
8. АЛЬТЕРНАТИВЫ БЕЗ АУДИО
==================================================

Если звук недоступен (мобильные устройства, тишина):
- Все звуки → визуальные подсказки (субтитры, эмодзи)
- BGM → анимированный эквалайзер (визуальный ритм)
- Laugh track → текстовая подпись "[Смех]"
- SFX → иконки звука (💧 🔪 🍳)
