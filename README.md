# Пирожки с нуля: Тесто Времени

Анимационный кино-мультик на 15 минут о том, как приготовить домашние пирожки с нуля. Таймингово-эвентовый формат с пошаговой инструкцией, режиссёрским режимом и laugh track.

## Формат

- **Хронометраж**: 15 минут (900 секунд)
- **Формат**: HTML5 Canvas 2D анимация
- **Разрешение**: 920×300 px (getFieldSize = 920)
- **Файловая структура**: movie.html — единственный файл с анимацией
- **Количество сцен**: 8
- **Количество шотов**: 49
- **Голосовые линии**: 87 (Шеф: 52, Диктор: 35)

## Персонажи

### Шеф-Повар «Шеф Вишенка»
- Высокий белый колпак (35% высоты тела)
- Красные вишенки на усах
- Анимированный персонаж, нарисованный в Canvas
- Позы: idle (покачивание), clap (хлопок), cook (готовка), eat (дегустация)
- Рисуется средствами Canvas (не эмодзи)

### Диктор
- Закадровый голос (текст)
- Объясняет процесс, даёт советы
- Стиль: тёплый, дружеский, поучительный

## Технические особенности

### Движок movie.html
- **Canvas 2D** — рендеринг всех сцен
- **Spline-анимация** — плавное движение через cubic-bezier кривые
- **Система частиц** — flour (мука), steam (пар), bubbles (пузырьки), sizzle (шипение)
- **Режиссёрский режим** — панель управления: camera X/Y, lighting, mood, animation speed
- **Laugh track** — после каждой сцены
- **Управление**: Play/Pause, Back, Speed + клавиатура (Space, ←/→, D)

### Управление

| Клавиша | Действие |
|---------|----------|
| Space | Play / Pause |
| → | Следующая сцена |
| ← | Предыдущая сцена |
| D | Открыть/закрыть режиссёрскую панель |
