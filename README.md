# Пирожки с нуля: Тесто Времени

## Описание проекта

Анимационный кино-мультик на 15 минут о том, как приготовить домашние пирожки из покупного теста с нуля. Таймингово-эвентовый формат с пошаговой инструкцией.

## Структура проекта

```
pacific/
├── README.md              # Этот файл
├── screenplay.txt         # Полный сценарий фильма
├── scenes_breakdown.txt   # Детальное разбиение на сцены и шоты
└── scenes/                # Папка для сцен (анимация, раскадровка)
```

## Формат

- **Хронометраж**: 15 минут (900 секунд)
- **Формат**: Таймингово-эвентовый анимационный фильм
- **Количество сцен**: 8
- **Количество шотов**: 49

## Эпизоды

| # | Название | Время | Длительность |
|---|----------|-------|--------------|
| 0 | Пролог | 0:00 - 1:30 | 90 сек |
| 1 | Пробуждение дрожжей | 1:30 - 4:00 | 150 сек |
| 2 | Смешение и замес | 4:00 - 7:00 | 180 сек |
| 3 | Настаивание теста | 7:00 - 9:00 | 120 сек |
| 4 | Приготовление начинки | 9:00 - 11:00 | 120 сек |
| 5 | Формировка пирожков | 11:00 - 13:00 | 120 сек |
| 6 | Выпечка | 13:00 - 14:30 | 90 сек |
| 7 | Дегустация (финал) | 14:30 - 15:00 | 30 сек |

## Ингредиенты

- Мука — 500 г
- Сухие дрожжи — 10 г (1 пакетик)
- Тёплая вода — 250 мл
- Сахар — 1 ст.л.
- Соль — 1 ч.л.
- Растительное масло — 2 ст.л.
- Фарш — 300 г
- Лук — 2 шт.
- Яйцо — 1 шт. (для смазывания)
- Зелень, соль, перец — по вкусу

## Персонажи

- **Шеф-Повар** — анимированный персонаж в высоком колпаке с усами-вишенками
- **Диктор** — закадровый голос, объясняет процесс

## Тайминговые эвенты

Таймер на экране ускоряется 6 раз:
1. Ожидание дрожжей (10 мин → 30 сек)
2. Замес теста (10-15 мин → 60 сек)
3. Настаивание теста (1 час → 120 сек)
4. Остывание начинки (10 мин → 30 сек)
5. Выпечка (25-30 мин → 60 сек)
6. Финальный таймер (900 сек = 15:00)
