РЕЖИССЁРСКИЕ ЗАМЕТКИ
=====================

ОБЩАЯ КОНЦЕПЦИЯ
===============
Фильм "Пирожки с нуля: Тесто Времени" — это таймингово-эвентовый анимационный фильм, который сочетает:
- Образовательный компонент (рецепт, техника)
- Развлекательный компонент (юмор, персонажи)
- Визуальный стиль (мягкая анимация, тёплые цвета)

СТИЛЬ АНИМАЦИИ
==============
- 2D, мягкие линии
- Тёплая палитра: коричневый, золотистый, белый
- Эффекты: пар, свечение, вибрация
- Крупные планы для деталей
- Общие планы для пространства

МУЗЫКА
======
- Жанр: лёгкий джаз / акустика
- Темп: средний, ускоряется при монтажах
- Инструменты: фортепиано, гитара, перкуссия
- Музыкальные темы:
  1. Основная тема (Шеф): весёлая, прыгающая
  2. Тема ожидания: медленная,大气ная
  3. Тема выпечки: нарастающая, торжественная
  4. Финальная тема: тёплая, уютная

ЗВУКОВЫЕ ЭФФЕКТЫ
================
- Мука: soft pouring, whispers
- Вода: gentle pour, splash
- Дрожжи: fizzing, bubbling
- Замес: squishing, kneading
- Нарезка: chop-chop, knife sounds
- Жарка: sizzle, ssssss
- Духовка: hum, timer ding
- Корочка: crack, crunch
- Аромат: whoosh, heavenly

ТАЙМИНГОВЫЕ ЭВЕНТЫ (детально)
==============================

1. 00:00 - 01:30  ПРОЛОГ
   - Знакомство с Шефом
   - Запуск таймера
   - Представление ингредиентов

2. 01:30 - 04:00  ДРОЖЖИ
   - Температура воды (37-40°C)
   - Добавление сахара
   - Активация (пузырьки)
   - Ожидание (таймер ускоряется ×20)

3. 04:00 - 07:00  ТЕСТО
   - Просеивание муки
   - Замес (ускорение ×15)
   - Формирование шара
   - Отправка на настаивание

4. 07:00 - 09:00  НАСТАИВАНИЕ
   - Таймлапс роста (×60)
   - Обминка
   - Деление на 12 частей

5. 09:00 - 11:00  НАЧИНКА
   - Нарезка лука
   - Обжарка (ускорение ×10)
   - Приправы
   - Остывание

6. 11:00 - 13:00  ЛЕПКА
   - Раскатка
   - Начинка
   - Защипы (крупный план)
   - Форма лодочки

7. 13:00 - 14:30  ВЫПЕЧКА
   - Разогрев духовки
   - Смазка яйцом
   - Выпечка (ускорение ×20)
   - Доставание

8. 14:30 - 15:00  ФИНАЛ
   - Разрез (крупный план)
   - Дегустация
   - Титры
